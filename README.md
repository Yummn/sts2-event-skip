# Event Skip / 跳过事件

## 功能

- 给所有普通事件和先古之民事件的初始选择页增加“跳过”。
- 跳过普通事件：直接离开，不获得额外奖励。
- 跳过先古之民：获得 200 金币。
- 跳过涅奥：获得 100 金币。
- 假商人等自定义事件原有的离开按钮会显示为“跳过”。
- 一旦选择了事件原本的选项，本事件后续页面不再显示“跳过”，避免先拿奖励再跳过。
- 不依赖 BaseLib，不含 PCK。

## 兼容版本

- 手机：Slay the Spire 2 v0.103.2
- 电脑：Slay the Spire 2 v0.107.1

## 安装

将压缩包内的 `EventSkip` 文件夹完整放入游戏的 `mods` 目录，并在启动器中启用。

文件结构：

```text
mods/
└─ EventSkip/
   ├─ EventSkip.dll
   ├─ EventSkip.pdb
   ├─ EventSkip.json
   └─ README-EventSkip.md
```
